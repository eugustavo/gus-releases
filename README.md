# Gus — instaladores

Instaladores e atualizações do **Gus**, ferramenta de design para macOS.

## Instalar

1. Baixe o `gus-<versão>.dmg` da [versão mais recente](https://github.com/eugustavo/gus-releases/releases/latest).
2. Abra e arraste o Gus para Aplicativos.
3. Na primeira abertura, o macOS pede confirmação: **Ajustes do Sistema → Privacidade e
   Segurança → Abrir Mesmo Assim**.

Requer Mac com Apple Silicon. Depois de instalado, o Gus se atualiza sozinho.

O código-fonte é privado; este repositório guarda só os instaladores.
